# Repository Guidelines & Rules

## Language Preference
- **Bilingual Output (Polish & English)**: Maintain documentation (such as `README.md`) and project communications in bilingual format (Polish and English).
- If providing both versions is not feasible, use **English** as the fallback.

## GitHub Repository Standards
- **Repository Metadata (About Section)**: Whenever managing, creating, or publishing a GitHub repository, always configure complete metadata:
  - **Topics (Tags)**: Always add relevant topic tags covering the technologies, frameworks, runtime, tools, and domain (for SEO and discoverability).
  - **Description**: Always provide a clear, concise description of the project.
  - **Website / Homepage URL**: Always configure the live deployment, demo, or documentation link (e.g. GitHub Pages URL).
  - **Badges & Visuals**: Include status badges (CI/CD, technologies, demo) in the README.
